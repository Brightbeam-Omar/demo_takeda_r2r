## Goal
Complete the seven-metric set by adding the signals that do not exist in the ERP: physical delivery (3PL), transfer notifications, sample ship dates and external-lab turnaround.

## Scope
- 3PL simulator: drop-folder CSV (`deliveries_YYYYMMDD.csv`, `transfers_*.csv`) generated by datagen and scenario steps; pipeline extract adds `stg_3pl_*`
- Delivery-date entry in the UI (planner): actual delivery date, location (3PL North / 3PL South / direct to site), PO ref, note → override fields `delivery_date`, `delivery_location`
- App-side metric computation for M1 (receipt on-time from physical delivery), M2 (transfer), M4 (QC ship from SME-entered ship date when LIMS lacks it), M5 (external lab ≤ 30 d) following the **signal-origin rule** (constitution P2); `metric_reference_v` switches to `active` for app-computed metrics via an app-side reference overlay
- Expected Delivery (pre-batch) view from open demand/PO lines: separate grain, separate card, never added to the pipeline total

## Acceptance sketch
- M1–M7 all render with values after `make demo-reset`
- Delivery entry starts the receipt SLA clock and is audited
- Expected Delivery count is shown separately and excluded from Total
